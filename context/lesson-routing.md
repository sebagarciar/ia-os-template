# Where each new lesson goes

Read when I correct you, or on `/wrap-up`. This is the one copy of the routing.

- A correction about **how something written in my name sounds or is framed** goes to
  `context/writing_style.md`, Part 2, not `MEMORY.md`.
- A **fact or decision specific to one folder** goes to that folder's `CLAUDE.md`. If the rule
  must be known even when that folder is not being touched, it stays in `MEMORY.md`, generalized.
- A correction about **how a skill behaves** goes in that skill's own `SKILL.md` or `references/`.
- Everything else (design, tools, architecture, how I communicate, data) goes to `MEMORY.md`.
- Rule files carry no dates, session logs or changelog lines.
