# Answer bank: standard answers for application forms

The `apply` skill reads this file for every form.

- A line marked **ASK** has no confirmed answer. Never guess it. Ask once, then write the answer
  here so nobody asks twice.
- Nothing is invented. If a form asks for something not listed here, ask.
- Text answers (motivation, challenge, pitch) are never stored here. They are written fresh per ad.

## Fixed facts (copy as is)

| Field | Answer |
|---|---|
| Full name | Alex Example |
| Email | alex@example.com |
| City / country | Springfield |
| Right to work | Citizen. No sponsorship needed. |
| Availability / start date | Immediately |
| Languages | English (native), Spanish (fluent) |
| Salary expectation | ASK |
| Date of birth, ID number, home address, gender | Leave empty unless I give the value in chat for that form |

## Rules for text answers

- Load `write-as-me`. Respect word and character limits exactly, and give the count.
- Answer in the form's language.
- Lead with the point, then the proof from the bank.
