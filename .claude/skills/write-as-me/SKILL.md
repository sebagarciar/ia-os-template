# Write as me

This skill only makes sure the style guide is read before writing. The rules live in one
place, `context/writing_style.md` in the repo root. Never copy rules from it into this file.

1. Read `context/writing_style.md` before writing a word: Part 1 in full, then the Part 2
   section for this audience. If no section fits, use "The default frame, everywhere".
2. For a CV, the `tailor-cv` skill owns the workflow and the facts. This skill only covers
   how it sounds.

When the user corrects how something sounds or is framed, the lesson goes into
`context/writing_style.md` Part 2, not here.
